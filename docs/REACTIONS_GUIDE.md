# Инструкция по работе с именами в реакциях

В данном обновлении была реализована поддержка отображения имен пользователей, которые оставили реакцию на сообщение. Это позволяет фронтенду (мобильному и веб-приложению) сразу показывать подсказку (tooltip) или список имен под сообщением без дополнительных запросов.

## 🛠 Техническая реализация

### 1. Изменения в БД и Моделях
В структуру `domain.MessageReaction` было добавлено поле `UserFullName`, которое заполняется при получении данных из БД через `JOIN` с таблицей пользователей (`users`).

```go
type MessageReaction struct {
    ID           uuid.UUID `json:"id" db:"id"`
    MessageID    uuid.UUID `json:"message_id" db:"message_id"`
    UserID       int64     `json:"user_id" db:"user_id"`
    UserFullName string    `json:"user_full_name,omitempty"` // Имя + Фамилия
    UserAvatar   *string   `json:"user_avatar,omitempty"`    // Ссылка на аватарку
    Reaction     string    `json:"reaction" db:"reaction"`
    CreatedAt    time.Time `json:"created_at" db:"created_at"`
}
```

### 2. Сводка реакций (ReactionSummary)
Для удобства отображения сервер группирует реакции по эмодзи. Теперь объект сводки содержит массив имен:

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `reaction` | string | Сам эмодзи (напр. "👍") |
| `count` | int | Общее количество таких реакций |
| `users` | []ReactionUser | Список объектов пользователей (id, full_name, avatar) |
| `reacted` | bool | `true`, если ТЕКУЩИЙ пользователь поставил эту реакцию |

## 📡 API Ответы

### Получение сообщений
Теперь при вызове `GET /api/v1/conversations/{id}/messages` или `GET /api/v1/groups/{id}/messages` каждое сообщение содержит актуальные имена в реакциях.

### Добавление/Удаление реакции
Методы `POST` и `DELETE` для реакций теперь возвращают не просто сообщение об успехе, а **весь список** обновленных реакций для этого сообщения.

**Пример ответа:**
```json
{
  "message": "reaction added",
  "reactions": [
    {
      "reaction": "🔥",
      "count": 2,
      "users": [
        {
          "id": 1,
          "full_name": "Иван Иванов",
          "avatar": "https://example.com/avatar1.jpg"
        },
        {
          "id": 2,
          "full_name": "Асхат Мусаев",
          "avatar": null
        }
      ],
      "reacted": true
    }
  ]
}
```

## 🔄 WebSocket Обновления

Когда любой пользователь ставит или убирает реакцию, сервер рассылает событие `message_reactions_updated` всем участникам чата.

**Структура события:**
```json
{
  "type": "message_reactions_updated",
  "content": {
    "message_id": "uuid-сообщения",
    "reactions": [ ... массив сводок с именами ... ]
  }
}
```

## 🔒 Правила видимости
*   Информацию видят **все участники** чата (и в личных, и в группах).
*   В поле `users` попадает подробная информация о пользователях (до 50 человек).
*   Если реакций больше, общее количество отображается в `count`.

## 💡 Рекомендация для Фронтенда
При получении ответа от API или события по WebSocket, рекомендуется полностью заменять локальный массив реакций сообщения на тот, что пришел от сервера. Это гарантирует 100% синхронизацию данных между пользователями.
