# Руководство по интеграции Alem Drive для мобильных приложений

Это руководство описывает, как правильно интегрировать веб-интерфейс редактора документов Alem Drive (OnlyOffice) в мобильное приложение через WebView.

## 1. Авторизация через токен (Seamless Login)

Чтобы пользователю не приходилось вводить логин и пароль при открытии документа в мобильном приложении, реализован механизм передачи токена через URL.

### Формат ссылки
Добавьте параметр `token` или `accessToken` к любому защищенному URL веб-приложения.

**Пример:**
`https://alem.workspace.com/drive/editor/FILE_ID?token=YOUR_JWT_TOKEN`

### Как это работает
1. Веб-приложение при загрузке проверяет наличие токена в URL.
2. Если токен найден, он сохраняется в `localStorage`, и сессия активируется автоматически.
3. После сохранения токен удаляется из адресной строки (через `history.replaceState`), чтобы он не оставался в истории браузера.

---

## 2. Настройка интерфейса (UI Modes)

Для мобильных приложений предусмотрены специальные режимы отображения, которые скрывают элементы навигации основного сайта.

### Режим "Без навигации"
При переходе по любому адресу, содержащему `/editor`, основная шапка Alem Workspace (поиск, профиль, уведомления) скрывается автоматически.

### Режим "Embedded" (Рекомендуется)
Чтобы получить абсолютно чистый экран (только редактор OnlyOffice без каких-либо кнопок самого сайта), добавьте параметр `embedded=true`.

**Пример:**
`https://alem.workspace.com/drive/editor/FILE_ID?embedded=true&token=YOUR_JWT_TOKEN`

**Что скрывается в режиме `embedded=true`:**
- Главная навигация сайта (Header/Sidebar).
- Внутренняя панель редактора (кнопка "Назад" и название файла).
- Все отступы и границы.

> [!IMPORTANT]
> В режиме `embedded=true` мобильное приложение **само** должно предоставлять способ вернуться назад (например, через нативную кнопку "Назад" в приложении или системную кнопку Android).

---

## 3. Рекомендуемый алгоритм открытия документа

Для наилучшего пользовательского опыта (User Experience) на мобильных устройствах рекомендуется использовать следующий URL:

```text
https://[DOMAIN]/drive/editor/[FILE_ID]?embedded=true&token=[USER_TOKEN]
```

### Преимущества этого подхода:
1. **Мгновенный вход**: Пользователь сразу видит документ без экрана логина.
2. **Максимум места**: Редактор занимает 100% экрана WebView.
3. **Нативный вид**: Интерфейс выглядит как часть мобильного приложения, а не как встроенный веб-сайт.

---

## 4. Чек-лист для разработчика мобильного приложения

- [ ] Убедитесь, что WebView имеет доступ к `localStorage` (нужно для сохранения токена).
- [ ] Убедитесь, что WebView разрешает выполнение JavaScript.
- [ ] Реализуйте нативную кнопку "Назад" для закрытия WebView.
- [ ] (Опционально) Передавайте актуальный токен при каждом открытии, чтобы избежать проблем с протухшими сессиями.

---

## Справочник параметров URL

| Параметр | Значение | Описание |
| :--- | :--- | :--- |
| `token` | JWT String | Токен доступа для автоматического входа. |
| `embedded` | `true` | Скрывает ВСЕ элементы управления веб-интерфейса. |
| `mode` | `edit` / `view` | (Опционально) Принудительно открывает в режиме редактирования или просмотра. |
