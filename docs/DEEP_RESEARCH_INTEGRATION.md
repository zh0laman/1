# Интеграция Deep Research Assistant (Tablet Mode)

Данный документ описывает процесс интеграции ИИ-ассистента Alem Drive в мобильное приложение (через WebView) для планшетных устройств.

## 1. Ссылка для входа (Entry Point)

Для открытия ассистента в полноэкранном режиме (без боковых меню и шапки сайта) используйте следующий URL:

```text
https://alem-workspace.gov.kz/web/drive/tablet/notebook
```

## 2. Автоматическая авторизация

Чтобы пользователь не проходил повторную авторизацию внутри WebView, мобильное приложение должно передать текущие JWT токены пользователя в параметрах запроса.

### Параметры URL:
*   `accessToken`: JWT токен доступа (Access Token).
*   `refreshToken`: Токен обновления (Refresh Token).

### Пример полной ссылки:
```text
https://alem-workspace.gov.kz/web/drive/tablet/notebook?accessToken=eyJhbGci...&refreshToken=eyJhbGci...
```

## 3. Особенности интерфейса (UX)

При использовании пути `/tablet/notebook` веб-приложение автоматически применяет следующие настройки:
1.  **Fullscreen**: Скрывается Sidebar (левое меню) и Header (верхняя панель).
2.  **Auth Sync**: Приложение автоматически сохраняет переданные токены в локальное хранилище браузера.
3.  **URL Cleanup**: Сразу после загрузки приложение удаляет токены из адресной строки (через `window.history.replaceState`), чтобы они не сохранялись в истории навигации WebView.

## 4. Рекомендации по реализации (WebView)

1.  **User Agent**: Рекомендуется использовать стандартный User Agent или добавить метку `Tablet`, чтобы стили применились корректно.
2.  **LocalStorage**: Убедитесь, что в WebView включена поддержка `DomStorageEnabled`, так как приложение хранит токены там.
3.  **Кэширование**: При смене пользователя на мобильном устройстве рекомендуется очищать кэш WebView или `localStorage`, чтобы избежать конфликта сессий.
